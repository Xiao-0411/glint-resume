识光简历 —— 上线问题清单 & 行动列表
=====================================
每条格式：问题描述 → 影响 → 建议方案


一、数据持久化（P0 - 必须做）
---------------------------------------

[x] 1. Session 内存存储替换为数据库
    问题：SessionStore 是 dict，进程重启全部丢失
    影响：用户对话记录、生成的简历全没
    方案：接入 MySQL，创建 users / sessions / messages / resumes 表

[x] 2. 简历数据持久化
    问题：生成后的简历只在内存里，没有落库
    影响：用户刷新页面就看不到自己刚才生成的简历了
    方案：在 resumes 表中存储简历 JSON，关联 user_id 和 session_id

[x] 3. 投递记录持久化
    问题：mock_get_applications 每次返回相同假数据
    影响：用户关掉浏览器，投递记录全没
    方案：创建 applications 表，真实记录每次投递


二、用户系统（P0 - 必须做）
---------------------------------------

[x] 4. 实现真实的注册/登录
    问题：登录弹窗（LoginDialog.vue）只模拟了登录动作，auth store 是假的
    影响：没有用户体系，数据无法归属于具体的人
    方案：JWT token + bcrypt 密码哈希；或者接入 Supabase Auth / Auth0

[x] 5. Session 与用户关联
    问题：当前 session 靠前端生成的随机 session_id，不绑定用户
    影响：切换设备/浏览器后，之前的简历全丢
    方案：登录后返回 user_id，所有 session/resume 关联 user_id


三、PDF 导出（P0 - 必须做）
---------------------------------------

[x] 6. 服务端生成真实 PDF
    问题：导出 PDF 调的是 window.print()，用户要自己操作浏览器
    影响：手机上几乎没法用；不够"专业"
    方案：后端用 WeasyPrint（Python）或 Puppeteer（Node）生成 A4 PDF，返回文件下载链接


四、职位&投递（P0 - 必须做）
---------------------------------------

[x] 7. 接入真实职位数据
    问题：JOB_DATABASE 只有 20 个硬编码假职位
    影响：用户搜不到真实岗位，产品核心价值打折扣
    方案：对接第三方招聘 API（Boss直聘开放平台/智联/猎聘），或定时抓取
    进展（2026-08-10）：
      - 猎聘打通，库里已有 2400+ 条真实职位，前端展示的是真岗位+原始链接
      - Boss直聘/智联被反爬挡住（详见 backend/app/crawlers/ 各模块顶部说明），已停用
      - 遗留：猎聘详情页有 IP 级配额，JD 正文靠每轮增量补全，覆盖率需要跑几天才上来
        没有 JD 的职位在前端标为「待评估」，不编造匹配分数

[ ] 8. 一键投递从 Demo 变真实
    问题：mock_apply_job 只是生成一个假 record
    影响：用户点了投递，实际什么都没发生
    方案：对接招聘平台的简历投递 API；或者至少自动打开投递页 + 自动填充简历信息


五、LLM 安全与成本控制（P0 - 必须做）
---------------------------------------

[x] 9. Token 消耗记录与费控
    问题：没有任何 token 计数和费用统计
    影响：不知道花了多少钱，被人刷接口也不敢停
    方案：每次 LLM 调用记录 token_in / token_out / 费用；加每日用户调用上限

[x] 10. 接口防刷
    问题：RATE_LIMIT_PER_MIN 默认关闭；按 IP 限流可被代理绕过
    影响：恶意刷 /api/chat 直接烧钱
    方案：基于用户 ID + IP 双重限流；加图形验证码

[x] 11. 用户输入安全
    问题：用户输入直接拼进 LLM prompt（prompts.py），存在 prompt injection 风险
    影响：恶意用户可能让 LLM 输出不当内容或泄露系统 prompt
    方案：对用户输入做敏感词过滤；prompt 模板与用户输入严格分离；加内容审核 API

[x] 12. API Key 安全管理
    问题：LLM_API_KEY 明文写在 .env 文件里
    影响：代码泄露 = Key 泄露 = 钱被盗刷
    方案：线上环境用云厂商密钥管理服务（阿里云 KMS / 腾讯云 SSM），或至少用环境变量注入


六、日志与监控（P0 - 必须做）
---------------------------------------

[x] 13. 结构化日志
    问题：全用 print() 打日志
    影响：出问题没法查，日志没有时间、级别、链路追踪
    方案：接入 Python logging + structlog，输出 JSON 格式日志

[x] 14. 错误追踪
    问题：LLM 调用失败自动 fallback 到 mock，用户完全不知道
    影响：运营方也不知道后台一直在报错
    方案：接入 Sentry，异常实时告警


七、部署与运维（P0 - 必须做）
---------------------------------------

[ ] 15. 域名 + SSL + CDN
    问题：当前只有 localhost:5173 和 localhost:8000
    影响：没法给用户用
    方案：购买域名，配置 SSL 证书，静态资源上 CDN

[ ] 16. 容器化部署
    问题：启动方式是人手工敲 uvicorn 和 npm run dev
    影响：不可靠，挂了不会自动重启
    方案：Dockerfile → docker-compose → 部署到云服务器，Nginx 反向代理

[ ] 17. 前端构建部署
    问题：前端用 npm run dev 跑开发服务器
    影响：开发服务器性能差，不适合生产环境
    方案：npm run build 生成静态文件，Nginx 直接 serve


八、产品体验（P1 - 最好做）
---------------------------------------

[ ] 18. 内容审核
    问题：用户输入和 AI 输出没有任何审核
    影响：可能生成敏感/违规内容，法律风险
    方案：接入阿里云/腾讯云内容安全 API

[ ] 19. 手机端体验
    问题：响应式布局勉强能看，但交互没做移动端适配
    影响：手机用户体验差
    方案：专门做移动端 UI 适配；底部导航栏；触摸手势

[ ] 20. 前端 SEO（SSR）
    问题：纯 Vue SPA，搜索引擎抓不到内容
    影响：百度/Google 搜不到你的网站
    方案：改为 Nuxt.js SSR，或至少首页做预渲染

[ ] 21. 文件存储
    问题：用户上传的 PDF 存在本地
    影响：服务重启丢失；无法横向扩展
    方案：接入阿里云 OSS / 腾讯云 COS

[ ] 22. 异步任务
    问题：简历生成时用户界面阻塞等待
    影响：生成慢的时候用户以为卡死了
    方案：Celery + Redis 做异步任务队列，前端轮询任务状态

[ ] 23. Prompt 配置化
    问题：所有 prompt 硬编码在 prompts.py 里
    影响：调 prompt 要改代码重新部署
    方案：prompt 模板存入数据库或配置文件，支持热更新

[x] 24. 错误兜底策略透明化
    问题：LLM 失败时偷偷切 mock，用户看不出区别
    影响：用户可能以为拿到了 AI 生成的结果，实际是假数据
    方案：fallback 时明确提示用户"当前 AI 服务繁忙，展示的是示例内容"


九、合规（P1 - 最好做）
---------------------------------------

[ ] 25. ICP 备案
    问题：中国大陆上线网站必须备案
    影响：不备案无法用国内服务器，域名无法解析
    方案：提前准备材料，备案周期 2-4 周

[ ] 26. 隐私政策 & 用户协议
    问题：没有隐私政策和用户协议
    影响：不合规，收集用户个人信息违法
    方案：起草隐私政策（说明收集什么数据、怎么用），用户注册时强制同意

[ ] 28. 简历评分模型微调
